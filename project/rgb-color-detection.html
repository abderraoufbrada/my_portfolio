RGB Color Detection System

A custom-built color identification system utilizing sequential LED illumination and an LDR sensor to determine object color based on reflected light intensity. Includes a 3D mechanical layout designed in Fusion 360.

Project Overview

This project focuses on a cost-effective alternative to dedicated RGB sensors. Instead of using a specialized IC like the TCS3200, the system employs a Red, Green, and Blue LED array paired with a single LDR (Light Dependent Resistor).

By sequentially pulsing each LED and measuring the analog response on the ESP32's ADC, the system identifies the dominant wavelength reflected by an object. This "ground-up" approach emphasizes sensor physics and analog signal integration.

Technical Approach

The firmware is written in C++ for the ESP32. It follows a specific logic cycle to ensure accuracy:

  • Sequential Pulsing: To avoid light mixing, only one color LED is active during each ADC reading.
  • LDR Stabilization: A short delay (100ms) is implemented between the LED activation and the sensor reading to allow the LDR to reach its photo-conductive steady state.
  • Comparative Logic: The three readings are compared to find the highest value (lowest resistance), indicating the primary reflected color.

Firmware Snippet

// Sample ESP32 Logic for Color Detection
void loop() {
  digitalWrite(redLed, HIGH);
  delay(100);
  redValue = analogRead(ldrPin);
  digitalWrite(redLed, LOW);

  digitalWrite(greenLed, HIGH);
  delay(100);
  greenValue = analogRead(ldrPin);
  digitalWrite(greenLed, LOW);

  // ... Logic for Blue and comparison follows
}

Mechanical Design

To ensure optimal sensor performance, I designed a 3D conceptual layout in Autodesk Fusion 360. The design features a specific component alignment to minimize ambient light interference and ensure that reflected light from the object is directed precisely toward the LDR's surface.
