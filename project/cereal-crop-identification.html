Cereal Crop Identification via Phenological Fingerprinting

Monitoring cereal crop health using Sentinel-2 satellite imagery, NDVI time-series analysis, and Random Forest classification on a 10×10 grid.

Project Overview

This project leverages satellite remote sensing and machine learning to identify and monitor cereal crops by analyzing their phenological fingerprint — the unique pattern of growth throughout the season.

Using Sentinel-2 imagery processed through Google Earth Engine, the system extracts NDVI time-series data and compares agricultural patches against a healthy reference crop using a trained Random Forest model.

Methodology

  • Extracted multi-temporal Sentinel-2 imagery over target agricultural regions.
  • Computed NDVI time-series for each patch.
  • Divided the study area into a 10×10 grid (100 patches).
  • Defined a labeled reference region with known healthy cereal crop growth.
  • Extracted key phenological features: Peak greenness, growth rate (rising slope), and decline rate (falling slope).
  • Trained a Random Forest model to compute similarity scores (0 to 1) for each patch.

Results & Visualization

The model generates a color-coded grid where:

  • 🟢 Green: High similarity to healthy crop phenology.
  • 🔴 Red: Low similarity (potential stress, different crop, or anomaly).

This approach enables efficient large-scale crop monitoring, early stress detection, and supports precision agriculture decisions.
