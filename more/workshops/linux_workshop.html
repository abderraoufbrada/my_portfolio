Workshop March 1, 2025

Introduction to Linux

Ubuntu Linux Fundamentals — Command Line, Security & Workspace Management

Hexagon Scientific Community — NSNN, Sidi Abdellah, Algiers, Algeria

Instructor

Prof. Slimane Azoug

Faculty Member — ESGEN Kolea, Algeria

Workshop Overview

This workshop provided a comprehensive introduction to the Ubuntu Linux operating system, designed for students and researchers looking to expand their IT skills beyond Windows environments. The session emphasized practical, hands-on learning with real-world applications in scientific computing and development workflows.

Key Learnings

Linux vs Windows

Understanding core differences in architecture, file systems, user permissions, and security models between Linux and Windows environments.

Command Terminal

Mastering essential bash commands for file navigation, directory management, process control, and system monitoring via the terminal.

Package Management

Using apt, snap, and other package managers to install, update, and remove software applications efficiently.

Workspace Organization

Best practices for directory structure, file permissions, environment variables, and organizing development projects.

Security Fundamentals

User authentication, sudo privileges, file access controls, and basic system hardening principles in Linux.

Dev Environment Setup

Configuring IDEs, compilers, version control (Git), and development tools for scientific and engineering workflows.

Skills Gained

Ubuntu Bash CLI Security System Admin File Management

Impact & Takeaways

This workshop was extremely beneficial in enhancing our IT skills and expanding our knowledge in the field of open-source computing. The ability to work confidently in a Linux environment is essential for modern scientific research, embedded systems development, and cloud computing workflows.

The practical skills acquired — from terminal navigation to package management — have directly supported subsequent projects involving Python development, IoT programming, and simulation tools that run natively on Linux platforms.
