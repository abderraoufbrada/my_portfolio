Robotics

Autonomous Navigation Robot

A fully autonomous mobile robot capable of SLAM (Simultaneous Localization and Mapping) with integrated computer vision for obstacle detection and path planning.

Duration 6 months
Team Size 4 members
Role Lead Designer

Project Overview

This project involved designing and building a mobile robot from scratch, including mechanical design, electronics integration, and software development. The robot uses ROS (Robot Operating System) for navigation and OpenCV for computer vision tasks.

Key Features

  • Real-time SLAM using LiDAR and RGB-D camera
  • Autonomous path planning with A* algorithm
  • Obstacle avoidance using ultrasonic sensors
  • Remote monitoring via web interface
  • 8-hour battery life with automatic docking

Technologies Used

ROS Python OpenCV Arduino SolidWorks 3D Printing

CAD Design

Turbine Blade Optimization

Topology optimization and CFD analysis of a gas turbine blade to improve efficiency and reduce material usage by 20%.

Duration 4 months
Software ANSYS, SolidWorks
Result 18% Efficiency Gain

Project Overview

Using generative design and topology optimization techniques, I redesigned a conventional turbine blade to reduce weight while maintaining structural integrity and improving aerodynamic performance.

Methodology

  • Parametric modeling in SolidWorks
  • CFD simulation in ANSYS Fluent
  • Topology optimization using Altair Inspire
  • FEA validation under thermal and mechanical loads
  • Prototyping via metal 3D printing

Key Results

18% Efficiency Increase
22% Weight Reduction
15% Cost Savings
